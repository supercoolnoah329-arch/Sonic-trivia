## Use notes

- These assets can provide panels, buttons, backgrounds, and level-like scenery for the trivia interface.
- Do not present these assets as official SEGA or Sonic artwork.
- The OpenGameArt tileset is ShareAlike: adaptations must use the same license, and the attribution above must remain with the project.
- Sonic-specific character art should be commissioned, drawn by us, or used only after obtaining explicit permission from the rights holder.
